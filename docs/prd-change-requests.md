# PRD change requests

Deviations made during implementation, with reasons. The founder accepts or rejects each.

| # | PRD | Change | Why | Status |
|---|---|---|---|---|
| CR-1 | D3 PostGIS | Geo matching uses **H3 cells (h3-js) + haversine in code**; PostGIS not required | Alpha scale is small; removes an extension dependency; the privacy model (latest snapped cell only) is unchanged | Proposed |
| CR-2 | D4 Redis/BullMQ | **In-process scheduler (@nestjs/schedule) + in-memory rate limiter**; durable limits (login codes) enforced in Postgres | One always-on instance in alpha; fewer moving parts and costs. Redis returns when scaling out | Proposed |
| CR-3 | PROF-002 signed PUT upload | **Direct multipart upload to the API**, validated and re-encoded server-side | Simpler on web and mobile; same security properties (magic bytes, re-encode, metadata stripped, private storage) | Proposed |
| CR-4 | D33 React admin | **Static HTML/JS admin client** served by the API at `/admin` | No extra build pipeline for alpha; all data still goes through `/admin/v1` with MFA | Proposed |
| CR-5 | D12 AI models | Card/report writer uses **`claude-opus-5-5` at low effort** with server-side refusal fallback (configurable via `AI_MODEL_WRITER`) | Follows current Anthropic guidance for model choice; cost is small (short outputs) and capped by `AI_DAILY_BUDGET_USD` | Proposed |
| CR-6 | D1 freezed/json_serializable | **Hand-written light models / JSON maps** in Flutter | Avoids a build_runner step for the alpha | Proposed |
| CR-7 | §14.3 report writer | Alpha reports use **deterministic localized templates** from engine codes (no AI prose yet) | Zero AI cost and fully predictable for the friends test; the AI writer can be layered on later | Proposed |
| CR-8 | Mini-IPIP ru | The 20 Mini-IPIP items use a **draft Russian translation** (not validated). Each answer stores the language it was shown in (`engine_answers.locale`) so ru answers can get separate norms or be re-asked after a validated translation. Deep Personality items stay in English for now | Testers didn't understand English items (alpha feedback 2026-10-17); IPIP items are public domain | Proposed (founder asked) |
| CR-9 | ENG-003 IPIP-NEO-120 | **O6 Liberalism (4 political items) excluded**; Deep Personality has 116 items, Openness uses O1–O5 | Political opinions are GDPR art. 9 special-category data and ENG-016 forbids such features | Proposed |
| CR-10 | §8.5 facet names | N facets shown inverted with positive names (Calm, Even temper, Steady mood, Social ease, Self-control, Resilience) | PRD forbids clinical labels ("Depression", "Anxiety") | Proposed |
| CR-11 | SOUL-002 SSE streaming | Guide replies are returned **whole** (typing indicator in the app) instead of streamed | Flutter web's HTTP client can't stream responses; 3–6 s replies are acceptable for the alpha. Streaming can be added for native clients later | Proposed |
| CR-12 | SOUL-002 rolling summary | The full session (≤ 20 turns) is sent instead of a rolling summary + last 8 turns | Sessions are capped at 20 turns, so context stays small | Proposed |
| CR-13 | SOUL-002 auto-finish after 7 days | Stale sessions are closed as `abandoned` without generating insights | Avoids AI calls from a background job; the user can start a new session | Proposed |
| CR-14 | ONB / PROF-002 | Interests, the Soul Profile reveal and share level can be **skipped** during onboarding (share level falls back to standard; 0 interests allowed). Age, terms, the Quick Scan (questions skippable one by one), the basics and **one photo** stay required; **one photo is enough** for matching (was 2) | Founder decisions 2026-10-17 | Proposed (founder asked) |
| CR-15 | §5.6 visual direction | Default palette is **neutral graphite**; Settings → Appearance offers System/Light/Dark and four palettes (Neutral, Sage, Sand, Coral), kept on the device | Founder request 2026-10-17 | Proposed (founder asked) |
| CR-16 | Alpha email | `EMAIL_PROVIDER=screen` shows sign-in codes on screen in the alpha (no email account). Refused by the server in staging/production | Founder: no paid services until "prepare for production" | Proposed (founder asked) |
| CR-17 | Accounts (new) | **Personas**: one sign-in can hold up to 3 fully separate profiles (own Quick Scan, photos, daily set, likes, matches, chats), switched in Me → My profiles. Others are not told that profiles belong to one person. Guards: age/consents copied from the owner and locked; profiles of one person never meet; a block against any profile covers all of them and ends their matches with the blocker; suspension covers all; deleting the owner deletes all; Soul+ is shared; push reaches the device whichever profile is active; admins see linked profiles | Founder decision 2026-10-17 ("fully separate profiles"). Trust risk noted: people may feel deceived if they learn two profiles are one person | Accepted by founder |
| CR-18 | PAY / monetization | Three paid levels instead of one Soul+: **Soul+** (25 Today's Souls/day, full reports), **Gold** (50/day, see who liked you + like back, rewind last pass, 100 likes/day), **VIP** (no daily limit, no like cap, sees how many profiles someone has — the number only; owners are told this in My profiles). Alpha: any level switches on for free (`/v1/billing/test-activate`, refused in staging/production); PAYWALL_ENABLED=true on Render | Founder request 2026-10-17 | Accepted by founder |
| CR-19 | ALPHA-002 | 100 demo profiles (topped up on every start), half of the new ones with Russian names/bios, 9 demo people with a second profile; demo profiles like each new tester once (up to 5) so "Liked you" can be tried | Founder request 2026-10-17 | Accepted by founder |
| CR-20 | S14 Today | Today's card can be **swiped** (right = like, left = pass) with a tilt and stamp; photos inside the card flip by tapping the left/right third (stories style); buttons stay for keyboard and screen readers. A **List** view (toggle in the app bar, remembered per device) shows everyone left today as a scrollable feed — one column on phones, 2–3 on wider screens — each with pass/like. Lists can be dragged with a mouse too. An empty day explains why (hidden, no photo, too many skipped answers) with a one-tap fix | Founder request 2026-10-17 | Accepted by founder |
| CR-21 | ENG-002 Quick Scan | Onboarding asks **10 starter questions** (one Mini-IPIP item per domain + values, kids, weekends, texting rhythm, closeness) instead of 36; a Quick Scan domain scores from one answer with confidence 0.25 (was ≥ 2 answers). The other 27 questions are offered in Soul → «Уточнить профиль». ENGINE_VERSION 2.2.0; golden pairs unchanged | Founder request 2026-10-17 ("only 10 questions") | Accepted by founder |
| CR-22 | ONB final step | Final step redesigned: «Всё готово!» with one primary «Начать знакомиться» (discoverable) and a quiet «Пока не показывать меня»; if the server still needs a step, the app opens that step instead of staying silent | Founder: "last step doesn't work" | Accepted by founder |
| CR-23 | RPT / S14 card | Cards and profiles show a **match percentage** (compatibility score rounded to 5) with the top 2 reasons on the card and up to 3 in the profile, plus "and N more things in common: find them out together". Individual trait scores stay hidden | Founder request 2026-10-18 | Accepted by founder |
| CR-24 | Brand | NearSoul mark: a friendly ghost-soul holding a heart (design/logo.svg); used for app icons, favicon, welcome and navigation | Founder request 2026-10-18 | Accepted by founder |
| CR-25 | Monetization: ads | Sponsored cards in Today's Souls for Free and Soul+: one after every 10 people (card stack and feed) and one at the end of the day; clearly labelled, closable, never in chats or match screens; contextual only (no personal data), aggregate impression/click counts. Gold and VIP have no ads. Alpha uses 3 labelled test ads | Founder decision 2026-10-18 | Accepted by founder |
| CR-26 | VIP: message first | VIP can write to someone in their Today's Souls without a mutual like (5/day). The recipient sees a request («Тебе написали первыми»), can view the profile, then reply (match + chat with that message) or decline. Recipient preferences, blocks and contact-info rules apply; writing first also counts as a like | Founder request 2026-10-18 | Accepted by founder |
| CR-27 | S14 Today / ALPHA-002 | Alpha Today's Souls holds up to **200 people a day** (DAILY_SET_SIZE default 200 in the alpha; Soul+ ≥ 25, Gold ≥ 50, VIP up to 300), loaded in pages of 30 as you go. A short day tops up every few minutes when new people join. **After every 50 people** a «Узнай себя» break card offers the next self-discovery questions (Пройти / Пропустить). **200 demo people** with illustrated portraits (never real photos), Armenian, Russian and international names, jobs and heights; demos accept any adult tester's age | Founder requests 2026-10-18 | Accepted by founder |
| CR-28 | Ads: partners with several venues | An ad card can list a partner's **locations** (name, address, maps link); «Адреса» opens the list and each opens in the maps app. The alpha uses a clearly fictional "Café Example (sample partner)" with 3 Yerevan venues.
